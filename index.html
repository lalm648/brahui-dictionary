English respelling 
ASCII accepted: sh=ş · zh=ź · LH=ļ · GH=ģ · T=ŧ · D=đ · R=ŕ · N=ń · aa=á · ii=í · uu=ú.

Not shortcuts, because they destroy real contrasts: tt dd rr are genuine geminates (baŧŧa, izzat) and kh gh ch are aspirated loan consonants (khuriyá, bhallo). For /x/ and /ɣ/ type x and ģ.

A capital at the start of a word is read as ordinary capitalisation, so Ná is ná and not ńá. Mid-word the shortcuts still hold, so baTTa is baŧŧa. If a word really begins with ŧ ń ş ź ģ ŕ đ ļ, type that letter.

Why the diacritics matter
Urdu text normally omits short-vowel marks, and a TTS engine guesses them from its own Urdu lexicon — which contains no Brahui words. Every output here is fully vocalized (zabar / zer / pesh / sukun) so the engine reads exactly what is written and the long–short vowel contrast survives. Feed the engine the vocalized string, never the bare consonant skeleton.
