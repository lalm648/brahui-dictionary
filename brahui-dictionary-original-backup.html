05Phrases

Published parallel sentences. Use these to hear connected speech rather than isolated words — intonation is where a word list stops helping.
Why the diacritics matter. Urdu text normally omits short-vowel marks, and a TTS engine guesses them from its own Urdu lexicon — which contains no Brahui words. Every output here is fully vocalized (zabar / zer / pesh / sukun) so the engine reads exactly what is written and the long–short vowel contrast survives. Feed the engine this vocalized string, never the bare consonant skeleton.
